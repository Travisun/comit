## 一、市场的空白在哪

写东西的技术人，今天只有五类去处，每类都替用户做了取舍：

| 替代品 | 他们的定位 | 留给我们的空白 |
| --- | --- | --- |
| 公众号 / 知乎 / 掘金 | 平台分发，内容为流量服务 | 主页是平台的模板页；三年的积累沉在信息流底 |
| 静态博客（Hexo / Hugo） | 完全主权、极客审美 | 没有读者，没有"随手一句"的出口，热情停在第三个月 |
| 即刻 / 微博 / X | 碎片社交，即时反馈 | 长内容死亡；时间线是流量生意，不留沉淀 |
| WordPress / 自建 | 主权 + 全能 | 运维与安全焦虑，写作变成第二份工作 |
| Medium / Substack | 写作优先、订阅制 | 没有中文技术社区；公式与图表不是一等公民 |

**结论**：全行业都在"主权"与"日常"之间二选一——要么保住领地失去读者，要么换来读者失去领地。没有人同时给出两者。这就是 comit.sh 的位置：

> **有社交的主权，有沉淀的日常。**

## 二、定位方案

五个候选方向（各自能赢的原因与风险）：

| # | 候选定位 | 能赢的原因 | 风险 |
| --- | --- | --- | --- |
| A | 技术人的自留地（主权叙事） | 精准踩中平台疲劳 | 农耕隐喻与 commit 隐喻不合 |
| B | 公开的实验记录本（科研叙事） | 科研/学子人群深且未被服务 | 对工程师偏窄 |
| C | 你的版本历史（把思考当作 repo） | 与命名、产品机制天然同构 | 抽象，需要故事托住 |
| D | 个人主页黄金年代的回归（怀旧叙事） | 对 30+ 技术人有强情感召唤 | 对没经历过的新人是"别人的乡愁" |
| E | 慢社区（反算法叙事） | 与所有 feed 形成道德区隔 | 单独用会显得清高 |

**选定：C 为主干，D 为情感层，E 为产品原则，B 作为楔子人群叙事。** C 与品牌名、产品机制（时间线 = log、导出 = clone、徽章 = 里程碑）完全同构，是唯一不需要"解释成本"的方向。

**最终定位声明**：

> comit.sh 是唯一为技术人打造的**"会生长的个人主页"**：每天随手 commit 的动态，与攒够三千字才发的长文，住进同一条时间线——主页自动替你长成作品集、履历和领地。不像平台 feed 让积累沉底，也不像静态博客让热情停更。

**三条支撑信息**（对外传播只说这三件）：

1. **一条时间线**：长文与动态同住，主页自动分流——深度不被碎片淹没，碎片不必等"够正式"。
2. **主页即领地**：可锁定的子域名、一键导出、RSS 与机器可读——你走的时候，东西带得走。
3. **记录有仪式**：commit 隐喻贯穿产品语言——动态是 commit，长文是 release，时间是 reviewer。

**定位纪律**：定位声明里的每一句话，都必须有产品事实兜底（分流、导出、子域名、RSS、徽章……）。说不到的功能不写进定位——情怀的底气是诚实。

## 三、平台故事（三幕）

**第一幕 · 仪式**
1956 年，MIT 的主机上跑着人类最早的「提交」之一——COMIT 语言。此后七十年，提交成为技术世界最通用的仪式：`git commit`、事务 commit、部署 commit。每一次提交都是一句简短的证词：*我思考过，我做过，此刻我在这里。*

**第二幕 · 失地**
后来，写东西的地方变了。平台收走了读者——你的文字成了别人信息流里的过客；静态站收走了心情——主权保住了，"今天写两句"的兴致却没了。技术人赢得了互联网，却弄丢了那个每天顺手留下一点什么的地方。

**第三幕 · 还乡**
comit.sh 把提交还给写的人。一句动态是 commit，一篇长文是 release；你的主页是仓库，时间线是 log。十年后回头看，`git log` 一拉，就是你这十年的思考史——**把想法，提交给时间，时间会替你保管。**

**叙事纪律**（继承 brand.md）：四个语源并列时保持同一节奏；COMIT Network 一条必须写明"同名不同命、与本项目无隶属关系"；故事可以在任何落点出现，但每次只讲一幕，不贪全。

## 四、为谁而建（四类人）

对应 /about 页的四象限。每张卡：画像 → 任务 → 痛点 → 收获 → 一个反直觉洞察。

**极客 · 工程师 ——「造东西的人」**
- 画像：后端 / 全栈 / 运维 / 独立开发者，常驻 Linux.do 与 GitHub。
- 任务：把项目过程、踩坑与 demo 公开沉淀，攒一份"可引用"的行业可见度。
- 痛点：公众号太重、X 与即刻无沉淀、静态博客停更；不想"运营账号"。
- 收获：主页即作品集；给面试官与合作方的永久链接；RSS / MCP 让机器替他值守。
- 洞察：**他们要的不是涨粉，是"可引用"**——被检索、被链接、被时间留住。

**科学家 · 科研者 ——「记录实验的人」**
- 画像：研究生、博后、实验室里写代码的人。
- 任务：把读文献、跑实验的日常变成可追溯的科研日志，毕业时不只剩几份 PDF。
- 痛点：论文周期以年计，日常记录无处安放；实验笔记散落在本地。
- 收获：KaTeX 与 Mermaid 是一等公民；科研日志即学术履历；研究发布有读者。
- 洞察：**他们不怕公开，怕"不够正式"被同行评判**——动态与文章分流，正好拆掉这堵心墙。

**学子 · 初入行者 ——「第一次 commit 的人」**
- 画像：大学生、转行者，learning in public。
- 任务：把学习过程公开记录，在简历之前先有一份成长轨迹。
- 痛点：没有作品可展示；怕在"大佬"面前露怯。
- 收获：低门槛动态流；邀请注册自动关注邀请人——第一天就有关注者；徽章为坚持作证。
- 洞察：**新人要的不是曝光，是"不丢人的起点"**——空态文案与仪式感就是为他们设计的。

**设计师 · 写作者 ——「跨语言的人」**
- 画像：设计师、产品、独立写作者，长短混合着发。
- 任务：发布过程与思考，排版要体面，语气要像自己。
- 痛点：微博排版失控，博客工具全为程序员设计。
- 收获：主题系统、封面与徽章、合集归档；投票组件可做轻调研。
- 洞察：**设计师是社区气质的放大器**——留住一个设计师，比多来十个程序员更能改变社区氛围。

四类人共享同一个敌人：不是"没有平台"，而是**"不够正式"的心理门槛**与**"没有积累"的时间焦虑**。产品的每个文案与机制，都应该至少拆掉其中一堵墙。

## 五、社区文化（五条宪法）

文化 = 价值观 × 被机制奖励的行为。每条：主张 → 反面（我们不做什么）→ 机制（产品怎么奖励它）。

**1. 长期主义 —— 记录 > 爆款**
- 反面：不做热搜，不插算法，不显示阅读数焦虑。
- 机制：时间倒序、按日期归档；徽章按"坚持"颁发（连续记录、周年）而非按流量。

**2. 作品感 —— 过程即内容，未完成也值得亮出来**
- 反面：不要求"干货"，不容忍内容农场腔。
- 机制：无标题动态流把门槛降到一句话；合集归档让碎片长成作品集；代表作置顶。

**3. 相互看见 —— 关注比推荐重要，回复比点赞重要**
- 反面：不做算法插序，不卖流量。
- 机制：关注即所见（/about 承诺"不为广告插队"）；@提及与互关私信；邀请码自动关注邀请人，让人际图谱自然生长。

**4. 领地与礼节 —— 领地内你说了算，公共区讲礼节**
- 反面：平台不审查你的主页长相，也不纵容公共区的失礼。
- 机制：可锁定子域名、一键导出、账户删除（领地主权）；审核链路透明、外链离站确认、内容标签（公共礼节）。

**5. 工程诚实 —— 披露所知，标注不确定**
- 反面：不装、不标题党、不用"下一代"体的话术。
- 机制：公式、图表、代码是正文的一部分；内容标签体系如实标注；安全与边界写进 [SECURITY.md](../SECURITY.md)。

## 六、氛围（这个社区闻起来是什么味道）

**意象：深夜的实验室 × 图书馆的阅览室。** 灯亮着，各做各的事，偶尔有人凑过来看一眼你的屏幕，说一句"这个有意思"。它不是广场（微博），不是酒吧（即刻），也不是会议室（工作群）。

机制与感官落点：

- **视觉**：留白与 1px 边框的克制；等宽字体里的数字给"记录感"；Cloudflare 橙只做点火色，不做底色。
- **文字**：短句、动词开头；空态是品牌最好的广告位（"时间线是空的 —— commit something."）。
- **声音**：没有"99+"、没有"爆"、没有热搜；只有"你关注的人有了新 commit"。
- **仪式**：第一次 commit、连续记录、周年徽章、年度报告（roadmap 项）——让时间在产品里可被感知。

## 七、文案方法与示例库

**"高端的情怀"的操作定义：克制的诗意 × 工程的诚实 × 历史的纵深。** 三者缺一：只有诗意是鸡汤，只有诚实是说明书，只有纵深是掉书袋。

五条写法规则：

1. **说人话，再说术语**——先具体后抽象，读者第一遍就要懂。
2. **一句话最多一个比喻**——隐喻只用家族内的词：commit、时间线、主页、领地、release、log。
3. **诗意靠名词与动词，不靠形容词**——"提交给时间"，而不是"美好地记录每一天"。
4. **数字与年代给文案以骨**——1956、七十年、三千字、第 100 天。
5. **情怀必须落到下一步动作**——每一处抒情，结尾都给一条可以立刻走出的路。

落点示例（可直接取用）：

| 落点 | 文案 |
| --- | --- |
| 品牌主张（全站） | 把想法，提交给时间。 |
| 注册成功 / 第一封邮件 | 欢迎。你的第一个 commit，一句话就够。 |
| 主页认领 | `comit.sh/{你的用户名}` 还空着——去认领它。 |
| 时间线空态（保持既有资产） | 时间线是空的 —— commit something. |
| 连续记录第 30 天 | 第 30 天。提交是会成瘾的，这里不戒。 |
| 周年邮件 | 一年前的今天，你 commit 了第一条。 |
| 邀请语 | 我在 comit.sh 的地址是 ×××。带上你的想法，来提交。 |

**主页地址统一写法**：一律写 `comit.sh/{用户名}`——实现为 `next.config.ts` 的 afterFiles 级 rewrite（`/{username}` ⇒ `/u/{username}`，真实路由与静态文件优先不受影响）；`/u/{用户名}` 为旧路径兼容，仍可达但对外文案不再使用。

**反例对照（为什么"生硬"）：**

| 生硬（旧腔） | 高端（新腔） | 差别 |
| --- | --- | --- |
| 立即注册，开启你的创作之旅！ | 你的用户名还空着——认领它。 | 感叹号换成了具体动作 |
| 赋能技术创作者 | 让写的人被看见。 | 去 buzzword，回到事实 |
| 拥抱 AI 的下一代内容平台 | LLM 帮你审内容，不替你写。 | 说清功能，不借势造词 |
| 海量优质内容等你发现 | 关注三个人，时间线就开始像你。 | 把"海量"换成可执行的第一步 |
| 赶紧发帖，赢取徽章！ | 连续第 7 天。徽章是自己长出来的。 | 催促换成时间本身 |
